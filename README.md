## 项目用途

计算机环境自动安装器适用于以下场景：

- 新装 Windows 后，一次性检查和准备运行库、开发工具、办公工具及常用辅助工具。
- 软件开发学习，快速配置 Node.js、Python、Java、Git、VS Code、MySQL 等基础环境。
- 数据库课程、后端项目和本地部署，安装 MySQL 服务、客户端、连接器和管理工具。
- 办公与文档处理，安装 LibreOffice、Pandoc、7-Zip，并接入用户自有的 Office 部署包。
- 嵌入式、科学计算和云原生入门，准备 Arduino IDE、R 和 kubectl。
- 已使用电脑的环境审计，识别缺失版本、旧版本、环境变量残留和可修复问题。

## 核心功能

### 自动扫描

程序启动后默认执行只读扫描，不会自动安装、卸载或修改系统。扫描已安装程序、注册表信息、命令行版本、服务、环境变量、端口和安装器管理目录，并以“已满足、未安装、版本较旧、检测中”等状态显示。

### 三种安装模式

1. **完整版安装**：选择当前缺失或低于目标版本的组件，尽量保留已满足的环境。
2. **全面替换安装**：选择完整套装并处理可安全识别的旧版本；涉及卸载时必须额外确认风险。
3. **自定义安装**：逐项勾选组件，依赖组件会自动加入计划，例如 pnpm 会自动要求 Node.js。

三种模式都必须通过平台授权、用户协议、安装路径、包文件校验和必要凭据检查。未同意用户协议时不能开始安装。

### 本地离线安装

随包的 22 个安装文件位于 `packages` 目录，总容量约 2.24 GB。安装器在执行前按清单校验 SHA-256，文件缺失或哈希不匹配会停止安装，不会自动从官网下载未知文件。因此国内用户可以先通过百度网盘或夸克网盘取得完整包，目标电脑安装时不需要访问 Node.js、MySQL、JDK、Python、VS Code 等官网。

MSI 约 72 MB，只安装主程序和快捷方式，不包含 2.24 GB 安装载荷。要完整离线安装，必须使用完整“可直接运行程序”目录，或者把匹配版本的 `packages` 目录放到 MSI 安装后的程序目录。

### 安装路径与环境变量

用户可以设置安装器管理的本地环境根目录。Maven、pnpm、Connector/J 等归档组件使用该目录；厂商 MSI/EXE 若不支持自定义目录，则遵循厂商安装规则。程序会检查目录是否可创建、是否可写，并在完成安装后刷新和审计机器级、用户级 Path、`JAVA_HOME`、`MAVEN_HOME` 等变量。

### MySQL 配置和数据保护

支持 MySQL Server、Workbench、Shell、Router、Connector/J 和 Connector/ODBC 的组合安装。用户可以设置 root 密码、服务名和端口；如果默认端口被占用，程序会提示并选择可用端口，不会停止无关服务。

更新、替换或重装已有 MySQL 时，程序必须先验证旧 root 密码，备份用户数据库并记录数据库、表、行数和摘要校验。恢复后再次核对结果；校验失败会停止流程并保留备份，不会静默删除旧数据目录。SQL 导入功能支持选择 SQL 文件、创建目标数据库并导入，密码不会写入日志或命令行。

### 授权、日志和错误处理

- 首次需要通过计算机资源共享平台完成设备授权；未授权时可以查看扫描结果，但不能执行安装和环境修复。
- 安装过程显示当前组件、阶段、总体进度和实时日志，完成或失败后自动重新扫描。
- 日志保存在 `%LOCALAPPDATA%\DevEnvironmentInstaller\Logs`。
- 无法自动恢复时，程序会先脱敏再上传错误摘要；密码、Token、Cookie 和授权信息不会写入报告。
- 网络不可用时不影响已具备本地安装包的安装流程；错误日志仍保存在本机供排查。

### 安全边界

- 只使用清单中指定的本地文件和哈希。
- 只卸载能够被 Windows 正确识别且提供安全静默卸载方式的组件。
- 不删除用户项目、源码、仓库、桌面文件和来源不明的便携程序目录。
- 管理员权限只在当前启动会话有效，不保存管理员 Token。
- Office、Navicat 和硬件驱动的许可、来源、兼容性及再分发责任由使用者自行确认。

## 新电脑推荐流程

1. 下载并完整解压“可直接运行程序.zip”，不要只复制 EXE。
2. 先阅读本说明和网盘 TXT，确认磁盘空间和管理员权限。
3. 启动程序，完成平台设备授权并等待只读扫描。
4. 选择环境套装；首次配置可选择“完整版安装”，需要统一重装时选择“全面替换安装”。
5. 设置环境根目录，确认 MySQL 端口和密码，阅读并同意用户协议。
6. 开始安装，观察实时日志，结束后检查自动重新扫描结果。
7. 新开 CMD 或 PowerShell，执行 `node --version`、`python --version`、`java -version`、`git --version` 等命令确认环境。

## 常见问题

**为什么 MSI 只有几十 MB？**  
MSI 是主程序安装壳，完整第三方安装包单独放在可直接运行版中，避免 Windows Installer 缓存超大 MSI 失败。

**没有网络能否安装？**  
取得完整 `packages` 后，随包组件可以离线安装。Office、Navicat 和具体硬件驱动不属于当前公开随包载荷，仍需用户准备合法本地包。

**为什么某个组件显示缺失？**  
先检查对应文件是否存在于 `packages`，再检查文件哈希和管理员权限；不要手动改名或重新压缩安装包。

**MySQL 更新会不会丢数据？**  
正常保护流程会先验证密码、备份并校验用户数据库；备份或恢复校验失败时应停止，不会继续覆盖旧数据。
